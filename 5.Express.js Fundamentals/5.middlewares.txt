The express app acts as a request handler
The user sends a request to the server, the app reads the requests, its type and forwards it to the appropriate route handler

Express allows us to define functions that are executed before the route handler
These functions are called middlewares, they are functions that are executed before the route handler
They have access to the request and response objects and can modify them
It also has access to the next function, which is the route handler that is executed after the middleware
The middlewares are executed in the order they are defined

Middlewares can do the following things:
1. It can read the request body
2. It can modify the request body
3. It can terminate the request-response cycle
4. It can forward the request to the next middleware or the route handler

If a middleware does no operation (neither terminate the response cycle nor forward the request to the next middleware), it will keep holding the request and the request will hand indefinitely.
Example:

const express = require("express");
const app = express();
app.use((req, res, next) => {
    console.log("Middleware 1");
});

If a middleware returns a response, it will terminate the request-response cycle and the response will be sent to the client
Example:

const express = require("express");
const app = express();
app.use((req, res, next) => {
    res.end("Middleware 1");
});


Middlewares can also be used to log the requests in a file
Example:

const express = require("express");
const fs = require("fs");
const app = express();
app.use((req, res, next) => {
    fs.appendFile("log.txt", `${req.method} ${req.url}\n`, (err) => {
        if (err) {
            console.log(err);
        }
    });
    next();
});
