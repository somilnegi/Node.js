Model View Controller (MVC) is a design pattern used in web development to separate the presentation logic from the business logic.

It is a popular architecture that helps in separating the concerns of the application and makes it easier to maintain and test the code.

According to it the application is divided into 3 parts:

1. Model: This is the data layer of the application. It contains the business logic and the data that is used by the application.

2. View: This is the presentation layer of the application. It contains the HTML, CSS, and JavaScript code that is used to display the data to the user.

3. Controller: This is the logic layer of the application. It contains the code that is used to handle the user input and update the model and view accordingly.
